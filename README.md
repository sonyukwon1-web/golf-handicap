# ⛳ 골프 모임 핸디캡

멤버 4명(최진규 · 최문창 · 손유권 · 이지수)의 라운드 스코어를 기록하고,
실제 성적을 기준으로 핸디캡을 자동 산정하는 정적 웹앱입니다.

서버가 없고 데이터는 브라우저 `localStorage`에 저장되며, JSON 파일로 내보내고
불러와서 멤버끼리 공유합니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/ 로 정적 빌드
npm run preview  # 빌드 결과 미리보기
```

## 핸디캡 산정 규칙

1. 멤버별로 **최근 5경기의 그로스 평균**을 낸다. 5경기가 안 되면 있는 경기만으로 평균을 낸다.
2. 평균이 가장 낮은 멤버가 **기준(핸디 0)** 이 된다.
3. 나머지 멤버의 핸디 = `반올림(본인 평균 − 최저 평균)`.
4. 넷 스코어 = `그로스 − 핸디`. 라운드 상세에서는 넷 스코어 오름차순으로 순위를 매기며,
   동점은 공동 순위다.

새 라운드를 저장하면 위 계산이 전부 다시 돌아가므로 핸디는 항상 최신이다.

### 과거 라운드에 적용되는 핸디

각 라운드 상세에 찍히는 핸디는 **그 라운드까지의 기록으로 계산한 그 시점의 핸디**다.
지난 결과가 나중 라운드 때문에 뒤바뀌지 않고, 가장 최근 라운드의 핸디는 홈 화면의
현재 핸디와 항상 일치한다.

### 불참 처리

특정 라운드에 빠진 멤버는 타수를 비워두면 된다. 그 라운드의 순위와 평균 계산에서 모두 제외된다.

## 스코어카드 사진 인식 (OCR)

“입력” 탭에서 스코어카드 사진을 고르면 [tesseract.js](https://tesseract.projectnaptha.com/)
가 브라우저 안에서 글자를 읽어 날짜 · 골프장 · 4명의 타수를 채워 준다. 사진은 어디로도
전송되지 않는다. 읽은 값은 저장 전에 입력 폼에서 그대로 고칠 수 있다.

- 한글 인식 모델(약 5MB)은 **처음 한 번만** 내려받고 이후에는 브라우저 캐시에서 읽는다.
- 총타수는 한 줄에서 50~200 사이 숫자 중 가장 큰 값으로 잡는다. 스코어카드는
  홀별 타수 → 전반/후반 → 합계 순으로 값이 커지므로 이 규칙이 총타수를 집어낸다.
- 날짜와 골프장은 상단 머리글에 작게 박혀 있어 통째로 읽으면 자주 누락된다.
  1차 인식에서 못 찾으면 머리글 띠만 3배로 확대하고 대비를 올려 한 번 더 읽는다.

### 이름 구분 팝업

스코어카드는 **내려받은 사람만 이름이 전부 나오고 나머지는 성만** 나온다.
최진규 · 최문창은 성이 같아서 “최 98타 / 최 100타”만으로는 누가 누군지 알 수 없다.

이럴 때 팝업이 떠서 타수마다 이름을 지정하게 한다.

- **최근 5경기 평균이 낮은 사람에게 낮은 타수**를 붙인 안을 “추천”으로 미리 골라 둔다.
- 같은 사람을 두 번 고르면 두 칸이 서로 자동으로 바뀐다.
- **동타면 팝업이 뜨지 않는다.** 누구에게 붙이든 결과가 같기 때문이다.
- `최*규`, `최○규`처럼 일부만 가려진 경우, 가려지지 않은 자리가 모두 맞으면서 후보가
  하나뿐이면 팝업 없이 자동으로 확정한다.
- “건너뛰기”를 누르면 나머지 두 명의 타수만 채우고 최씨 두 칸은 비워 둔다.

## 데이터 공유

- **내보내기** — 전체 기록을 `골프핸디캡_YYYY-MM-DD.json` 파일로 저장한다.
- **불러오기** — 받은 JSON 파일을 열면 현재 기록을 그 파일 내용으로 대체한다(덮어쓰기 전 확인창이 뜬다).

기록을 관리하는 사람이 라운드를 입력하고 파일을 단톡방에 올리는 식이 가장 단순하다.

## 배포

### GitHub Pages

저장소 **Settings → Pages → Source** 를 `GitHub Actions` 로 바꾸고 `main` 에 푸시하면
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) 이 알아서 빌드·배포한다.

### Vercel

저장소를 import 하면 Vite 프로젝트로 자동 인식된다. 수동 설정이 필요하면
빌드 명령 `npm run build`, 출력 디렉터리 `dist`.

`vite.config.js` 의 `base: './'` 덕분에 루트 도메인이든 `/<저장소이름>/` 하위 경로든
그대로 동작한다.

## 구조

```
src/
  lib/handicap.js      핸디캡·순위·추이 계산 (순수 함수)
  lib/storage.js       localStorage 저장, JSON 내보내기/불러오기, 입력값 정규화
  components/
    Dashboard.jsx      멤버 카드 + 차트 + 최근 라운드
    TrendChart.jsx     평균 타수 추이 라인 차트 (의존성 없는 SVG)
    RoundList.jsx      라운드 목록 · 넷 순위 상세 · 수정/삭제
    RoundForm.jsx      여러 라운드 연속 입력
    RoundFields.jsx    입력 필드 (신규·수정 공용)
    ScorecardImport.jsx  스코어카드 사진 인식 패널
    NameResolver.jsx     성이 겹치는 멤버를 구분하는 팝업
  lib/ocr.js           tesseract.js 래퍼, 머리글 확대·대비 보정
  lib/scorecard.js     OCR 텍스트 파싱, 이름 → 멤버 매칭
```

멤버 이름을 바꾸려면 [`src/lib/handicap.js`](src/lib/handicap.js) 의 `MEMBERS` 와
`MEMBER_COLORS` 를 함께 수정하면 된다.
